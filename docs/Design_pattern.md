# 디자인 패턴

본 프로젝트는 유지보수성과 확장성을 고려하여 검증된 소프트웨어 설계 방법론과 디자인 패턴을 채택했습니다.<br/>
"도메인 로직의 순수성 보장"을 목표로 채택되었습니다.

## 방법론

### 도메인 주도 설계

소프트웨어의 복잡성을 관리하기 위해 비즈니스 도메인을 중심으로 설계하는 방법론을 적용합니다.<br/>
기술적인 구현보다 비즈니스 규칙과 정책을 코드에 투영하는 것을 최우선으로 합니다.

---

다음과 같은 흐름으로 개발을 진행합니다.

1. 도메인 분석: 핵심 비즈니스 규칙을 파악하고 Aggregate 식별 및 Bounded Context 작성
2. 단위 테스트: Hexagonal Core(Application/Domain)는 Test Code로 모두 보장.
